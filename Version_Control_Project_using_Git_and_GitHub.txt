Version Control Project using Git & GitHub

Description This assignment demonstrates the complete Git and GitHub
workflow, including repository creation, commits, branching, merging,
and remote repository management.

------------------------------------------------------------------------

Step 1: Create a Local Repository

mkdir VersionControlProject cd VersionControlProject git init

------------------------------------------------------------------------

Step 2: Create Project Structure

VersionControlProject/ │ ├── src/ ├── public/ ├── README.md ├──
.gitignore ├── package.json └── index.html

------------------------------------------------------------------------

Step 3: Create a GitHub Repository

1.  Sign in to GitHub.
2.  Click “New Repository”.
3.  Enter repository name.
4.  Select Public.
5.  Click Create Repository.

------------------------------------------------------------------------

Step 4: Connect Local Repository

git remote add origin
https://github.com/your-username/VersionControlProject.git

Verify: git remote -v

------------------------------------------------------------------------

Step 5: Add and Commit Files

git add . git commit -m “Initial project setup”

Make more changes and create additional commits:

git commit -m “Added project structure” git commit -m “Updated README
documentation” git commit -m “Fixed application layout”

Use meaningful commit messages.

------------------------------------------------------------------------

Step 6: Create and Use a Branch

git checkout -b feature-ui

Make changes:

git add . git commit -m “Added new UI feature”

------------------------------------------------------------------------

Step 7: Merge Branch into Main

git checkout main git merge feature-ui

------------------------------------------------------------------------

Step 8: Resolve Merge Conflicts (if any)

If Git reports a conflict: 1. Open the conflicting file. 2. Remove
conflict markers. 3. Keep the correct code. 4. Save the file. 5. Run:
git add . git commit -m “Resolved merge conflict”

------------------------------------------------------------------------

Step 9: Push Code to GitHub

git push -u origin main
