Step 3: Basic GitHub Workflow

1.  Clone the repository git clone
    https://github.com/your-username/project.git

2.  Create a new branch git checkout -b feature-branch

3.  Make changes

4.  Stage files git add .

5.  Commit changes git commit -m “Added new feature”

6.  Push changes git push origin feature-branch

7.  Create a Pull Request

8.  Merge after review

------------------------------------------------------------------------

Step 4: GitHub Issues and Pull Requests

GitHub Issues - Used to report bugs. - Suggest new features. - Track
project tasks.

Pull Requests - Used to submit code changes. - Team members review the
code. - Changes are merged after approval.

------------------------------------------------------------------------

Step 5: Git Best Practices for React Projects

-   Write meaningful commit messages.
-   Use feature branches.
-   Keep node_modules in .gitignore.
-   Commit small changes frequently.
-   Pull latest changes before pushing.
-   Keep README.md updated.
-   Never upload .env files.
-   Review code before merging.

------------------------------------------------------------------------
