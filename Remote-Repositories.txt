Module: Working with Remote Repositories

Assignment Title: Managing Code with Remote Git Repositories

Description

Step 1: Push Code to GitHub

git add . git commit -m “Updated project files” git push origin main

Step 2: Pull Updates from Remote Repository

git pull origin main

Step 3: Clone a Repository

git clone https://github.com/your-username/GitDemo.git

Move into the cloned repository:

cd GitDemo

Step 4: Verify Remote Repository

git remote -v

Step 5: View Commit History

git log –oneline

Explanation

1.  git push Uploads local commits to the remote GitHub repository.

2.  git pull Downloads the latest changes from the remote repository and
    merges them into the local repository.

3.  git clone Creates a complete copy of a remote repository on your
    local computer.

Origin and Main

Origin: - The default name of the remote GitHub repository. - Example:
git push origin main

Main: - The default primary branch of the repository where the latest
stable code is stored.

Real-Life Collaboration Workflow

1.  Clone the shared repository.
2.  Create a new branch for your work.
3.  Make changes and commit them.
4.  Push the branch to GitHub.
5.  Create a Pull Request.
6.  Team members review the code.
7.  After approval, merge the changes into the main branch.
8.  Pull the latest changes using git pull origin main.

Evaluation Criteria

1.  Correct use of git push, git pull, and git clone.
2.  Local and remote repositories remain synchronized.
3.  Origin and main are explained correctly.
4.  Real-life collaboration workflow is explained clearly.
5.  Commands are executed correctly.
